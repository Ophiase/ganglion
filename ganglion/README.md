# Ganglion

A project's **small brain**: the part it exposes to a second brain.

- a *ganglion*: a cluster of neurons outside the brain, working on its
  own, still wired to it
- readable **without** Obsidian (GitHub, ADO, an editor), pluggable
  **into** Obsidian
- lives in a **native project**: built for a brain, agentic from birth
